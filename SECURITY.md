# Security

Beacon holds write access to AWS resources on purpose, so its safety model is
the product. The controls, and the test that proves each one, are listed in
[docs/safety.md](docs/safety.md); the production-hardening claims are in the
README's "Production notes" and in `tests/test_template_ops.py`.

## What a deployment exposes

- Two public Lambda Function URLs behind CloudFront-scoped CORS. Reads are
  redacted (no account ids or ARNs). Writes need the `x-beacon-passcode`
  header, compared in constant time; an unset passcode fails closed.
- The only write actions anywhere are `ec2:AuthorizeSecurityGroupIngress`
  and `ecs:UpdateService`, on a separate role, scoped by
  `aws:ResourceTag/beacon:remediable=true`, executed only after an approval
  record that quotes the engineer's transcript. `make apply-off` disables all
  of it.
- Secrets: the passcode is a CloudFormation `NoEcho` parameter; the demo
  database password is generated by RDS into Secrets Manager; the optional
  AssemblyAI key, the Telegram bot token and the GitHub token live in SSM
  SecureStrings (`/beacon/<stack>/…`). The Telegram webhook secret and the
  allowlist of user ids are `NoEcho` parameters. Nothing secret is in git.
- Telegram: only user ids on the allowlist are answered; the webhook is
  refused (401) without the secret Telegram echoes back; voice-note files are
  downloaded by the Lambda and uploaded to AssemblyAI, so the bot token
  (embedded in Telegram file URLs) never reaches a third party.
- GitHub: `open_fix_pr` needs a fine-grained token scoped to one repository
  (Contents + Pull requests); it opens branches and pull requests and cannot
  merge. It runs only after the engineer's phrase and only on a resolved
  incident with an approval record.

## Reporting

Open a GitHub issue titled `security:` for anything that is not exploitable
in a deployed stack (docs, tests, hardening ideas). For anything exploitable,
email the maintainer listed under `authors` in `pyproject.toml` instead of
filing a public issue; expect an answer within 48 hours.
